Text conversion

Text to Env Var List

Turn one value per line into a comma-separated environment variable value.

Leave blank for a comma-separated value. Add a name for a single .env assignment.
Paste your values to get started.Text stays in this browser.

How to use

  1. Paste one value per line.
  2. Choose whether to trim spaces and skip empty lines.
  3. Copy your result into your application.

Output format

Leave the variable name blank for a value list, or enter FEATURES to generate a single assignment such as FEATURES='feature_a,feature_b'. Download it as .env. This converts a list into one variable; it does not parse multiple KEY=VALUE entries. Single quotes in assignment values are rejected because dotenv parsers handle them differently. Commas inside a value remain commas; check how your application parses them.

apple
banana
cherry → apple,banana,cherry
